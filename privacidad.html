Información básica sobre los datos relacionados con esta web y las opciones de contacto.

ÚLTIMA REVISIÓN · OCTUBRE 2026

1. Responsable

Este sitio se presenta como la web profesional de Billy — The Grid GRX, diseñador gráfico en Granada. Antes de publicar esta página en internet, completa aquí tus datos de identificación legal y un medio de contacto de privacidad. La información del perfil público de Google Maps no sustituye los datos legales del titular.

2. Datos recogidos por esta web

El formulario de contacto funciona en tu dispositivo y prepara un mensaje para abrir WhatsApp. Esta web no transmite el formulario a un servidor ni almacena su contenido. Si decides enviar el mensaje desde WhatsApp, se aplicarán las condiciones y la política de privacidad de ese servicio.

El alojamiento web y los servicios externos que decidas activar (por ejemplo, fuentes de Google) podrían procesar datos técnicos como la dirección IP conforme a sus propias políticas. Revisa esos servicios y las obligaciones aplicables antes de publicar.

3. Finalidad y base jurídica

Si envías un mensaje por WhatsApp, los datos que incluyas se utilizarán para responder a tu consulta o gestionar una posible relación profesional. El tratamiento se basa en tu solicitud y, cuando corresponda, en la adopción de medidas precontractuales.

4. Conservación y derechos

Los mensajes se conservarán solo durante el tiempo necesario para atender la consulta y cumplir las obligaciones legales aplicables. Puedes solicitar acceso, rectificación, supresión, limitación u oponerte al tratamiento contactando con el titular por los medios que se publiquen en esta página.

5. Cambios

Esta información debe revisarse y completarse por el titular antes de publicar la web. No constituye asesoramiento jurídico.
