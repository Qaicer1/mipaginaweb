# The Grid GRX — sitio web en un solo archivo

Abre `index.html` en el navegador. Incluye las páginas principales como secciones navegables, junto con el CSS, JavaScript y la fotografía local incrustados. No necesita los otros archivos HTML, CSS, JavaScript ni la carpeta `assets/` para funcionar; las fuentes de Google Fonts y la fotografía de referencia de Unsplash necesitan conexión a internet. También se incluye una versión multipágina con estilos compartidos.

## Rediseño profesional (v2)

Esta versión es un rediseño completo del sitio, pensado para verse más profesional y atractivo:

- Sistema de diseño renovado (tipografía editorial **Fraunces** + **Manrope** + **DM Mono**, paleta cálida, sombras suaves, cristal esmerilado y microanimaciones).
- **Ilustraciones SVG elegantes para cada servicio** dibujadas a medida: identidad visual (construcción de logotipo), diseño para redes (marco de publicaciones), gráfica impresa (piezas y marcas de corte) y menú QR (código QR verificado).
- Ilustración de portada, composiciones para cada proyecto del portfolio y artes grandes en las páginas de servicio, todo en SVG vectorial (nítido en cualquier pantalla y sin peso extra).
- Animaciones de aparición al hacer scroll, marquesina de especialidades y cabecera con estado al desplazarse.
- Secciones nuevas: banda de cifras, preguntas frecuentes y paginación entre proyectos.
- Accesibilidad: enlace para saltar al contenido, roles ARIA, foco visible y soporte de `prefers-reduced-motion`.
- Servicio SaaS de gestión para restaurantes con planes mensuales sugeridos, puesta en marcha y límites sujetos a presupuesto. La imagen ilustrativa procede de Unsplash.

La demostración del menú QR es ficticia y no envía pedidos. El formulario prepara un mensaje en WhatsApp para que la persona lo revise y lo envíe; el sitio no almacena ni transmite los datos a un servidor.

## Antes de publicar

1. Completa y revisa los textos legales con tus datos reales y, si procede, asesoramiento profesional.
2. Comprueba que todos los servicios y precios sugeridos coinciden con lo que ofreces y valida el alcance, alojamiento, soporte e integraciones antes de ofrecerlos.
3. La fotografía del nuevo servicio se carga desde Unsplash; revisa su disponibilidad y licencia antes de publicar.
4. Verifica que el teléfono y el enlace a Google Maps siguen siendo correctos.
